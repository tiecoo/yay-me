# Diretrizes para Agentes de IA e Desenvolvedores

Este arquivo contém as regras e convenções de fluxo de trabalho obrigatórias para agentes de IA e desenvolvedores trabalhando neste repositório.

## 1. Convenção de Branches
- **Sempre** crie novas branches utilizando o prefixo `feature/`.
  - Exemplos: `feature/adicionar-sdd-template`, `feature/configurar-agentes`.

## 2. Atualização de Documentação (README)
- **Sempre** atualize o [README.md](file:///c:/Users/diego/Repos/yay-me/README.md) antes de realizar um `git push`.
- Garanta que novas funcionalidades, alterações na estrutura do projeto ou novas dependências estejam refletidas no README.
